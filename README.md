CURSE is an automated, high-performance ROM sorting engine designed to structure massive No-Intro and Redump sets. 
The engine analyzes the file names and automatically redistributes each ROM into its definitive location based on a deeply refined system of predefined categories, regions, and revisions. 
Built as a self-contained, monolithic utility, it delivers rapid file-system execution without the need for complex external configurations or user setup.
